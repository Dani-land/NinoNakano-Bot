# Nino Nakano-MD

## Ejecutar el bot

- Requiere Node.js `21.7.3` o superior.
- Instalar dependencias: `npm install`
- Iniciar: `npm start`
- La primera ejecución solicita QR o código de vinculación y guarda la sesión en `Sessions/Owner`.
- No borres `Sessions/Owner` salvo que quieras vincular el bot de nuevo.

El proyecto usa Node 22 en Replit porque es la versión compatible más cercana disponible; satisface el requisito mínimo de Node 21.
